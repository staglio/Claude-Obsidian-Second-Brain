Second brain for **Intro to Machine Learning**. Start from the root map: [[ML Fundamentals]].

## Workflow
1. **Capture** — dump anything into `00 Inbox/`. Messy is fine: bullet points, typos, questions.
2. **Process** — open Claude Code on this folder (desktop app **Code** tab, or `claude` in a terminal), then type `/process`.
3. **Review** — read the report, check any `[!warning]` flags, promote notes from `seedling` to `growing`/`evergreen` when you really understand them.

## Commands
| Command | Use it when |
|---|---|
| `/process` | the inbox has something in it |
| `/connect <note>` | a note feels isolated, or (no argument) to find orphan notes |
| `/ask <question>` | you want an answer from *your* notes, with citations |
