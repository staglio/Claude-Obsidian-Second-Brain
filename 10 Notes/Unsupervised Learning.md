Learning from data that has no labels: the model has to find structure on its own. Examples from the lecture: clustering (grouping similar customers) and dimensionality reduction (squeezing many features into a few).

> "No right answer to compare to, so it's harder to say if the model is good."

## Connections
- It uses only the features from [[Features and Labels]] — there is no label to predict.
- Contrast with [[Supervised Learning]], where every example comes with the right answer.
