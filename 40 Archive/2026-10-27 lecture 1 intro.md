lecture 1 - what is ML

- ML = computer learns rules from data instead of us programming the rules
- supervised: we have examples + the right answer (label). learn x -> y
  - regression -> predict number (house price)
  - classification -> category (spam/not spam)
- unsupervised: no labels. find structure. clustering (customer groups), dim reduction
  - no right answer to compare to, so it's harder to say if the model is good
- features = inputs (size, rooms...), label/target = what we predict
