How a model actually learns: define how wrong it is, then reduce that step by step.

## Core concepts
- [[Loss Function]] — the number we minimize
- [[Mean Squared Error]] — the standard loss for regression
- [[Gradient Descent]] — walk downhill on the loss
- [[Learning Rate]] — how big each step is
- [[Feature Scaling]] — makes gradient descent converge faster
